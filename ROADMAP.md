# План до Google Play

Порядок важен: сначала то, без чего игру нельзя выпустить и нельзя измерить, потом то, что её усиливает.
Отметки `[x]` — сделано, `[ ]` — впереди.

Как работаем: каждое изменение проверяем в браузере и на сайте (rings.sekond.pl), коммитим и отправляем в GitHub; Android-приложение собираем и ставим на телефон только на значимых законченных этапах.

Оформление, управление, скины, достижения, сложность и рейтинги спроектированы вместе — см. [docs/design.md](docs/design.md). Порядок шагов там: корпус и ЖК-табло → сложность → скины стран и переводы → достижения → уровни и испытание дня → Google Play Games.

## 1. Android-сборка (Capacitor)

Веб-игра заворачивается в нативное приложение — снимает браузерные костыли.

- [x] Capacitor-проект: `npm run android` собирает релиз в `dist/`, проверяет его и переносит в `android/`
- [x] Ориентация закрепляется нативно (альбомная), без поворота кадра через CSS
- [x] Аппаратная кнопка «Назад»: в игре — пауза, на паузе — продолжить, в меню — свернуть
- [x] Вибрация через нативный модуль, полноэкранный режим без строки состояния, экран не гаснет во время партии
- [x] Отладочный APK собирается (Gradle 9.1 — шаблонный 8.14 не работает на Java 25 из Android Studio)
- [ ] Проверка на настоящих телефонах, включая слабый Android
- [ ] Иконка и заставка запуска

## 2. Уровни и прогрессия

Решено (2026-10-28): игра только альбомная, переключателя нет. Уровни и баланс рассчитываются под широкое поле (648×360): на нём помещаются три-четыре штыря, препятствия и несимметричные раскладки.

- [ ] Раскладки уровней на основе `FIELDS` (штыри, сопла, полки, число и размер колец)
- [ ] 30–50 уровней, 1–3 звезды за время, открытие по порядку
- [ ] Сложность уровня — в том числе сила, с которой кольца стремятся лечь плашмя (`ALIGN`, `PHI_ALIGN`): слабее — больше кувыркаются, труднее надеть. Значения подбирать ботами (`tools/tune.mjs`)
- [ ] Три уровня сложности на выбор (лёгкий / обычный / трудный) — прежде всего через ту же силу выравнивания колец
- [ ] Ежедневное испытание: одна раскладка у всех в мире (фиксированное зерно случайностей)

## 4. Монетизация

- [ ] AdMob: реклама за награду (продолжить, +время, подсказка) и межстраничная — между партиями, не чаще раза в 2–3 игры, не в первой сессии
- [ ] Разовая покупка «Без рекламы» через Google Play Billing (реклама за награду остаётся по желанию)
- [ ] Окно согласия на рекламу и данные для ЕЭЗ (Google UMP) — обязательно в ЕС

## 5. Рекорды
