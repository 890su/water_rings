# Кольца — водная игра

Браузерная версия водной игры из детства: в аквариуме с водой два насоса, нажимая на них, нужно струёй закинуть кольца на штыри.

Вода честно симулируется (stable fluids на сетке 30×54), кольца — жёсткие пары частиц, которые тонут, планируют и кувыркаются в потоке.

## Запуск

Открыть `index.html` в браузере — сборка и зависимости не нужны. На телефоне лучше в полноэкранном режиме.

## Онлайн

Играть с телефона: https://rings.sekond.pl (прежний адрес workers.dev тоже работает).

Выложить новую версию (Cloudflare Workers, нужен вход: `npx wrangler login`):

```bash
npm ci
npm run deploy
```

Перед каждой публикацией Wrangler автоматически собирает защищённую версию и проверяет её соответствие исходной. Наружу уходит только `dist/index.html`; исходный `index.html`, инструменты и зависимости не публикуются.

## Android-приложение

Обёртка Capacitor в `android/`, идентификатор `com.waterrings.game` (временный — подтвердить до первой загрузки в Google Play). Нужна Android Studio (Android SDK и Java 21).

```bash
npm ci
npm run android        # релизная сборка, проверка и перенос в android/
npm run android:open   # то же и открыть проект в Android Studio
```

В приложении ориентация закрепляется нативно, кнопка «Назад» ставит на паузу / продолжает / сворачивает, вибрация через модуль Haptics, экран не гаснет, системные панели скрыты. План до выпуска — в [ROADMAP.md](ROADMAP.md).

## Защита релиза

`npm run build` создаёт `dist/index.html`: Terser переименовывает внутренние переменные и функции, убирает комментарии и лишние пробелы. Скрипт заключён в замыкание и не выставляет свои функции в глобальную область. HTML, CSS, интерфейс и свойства объектов сохранены. Исходники остаются в корневом `index.html` для разработки и симуляций.

Намеренно отключены оптимизирующие преобразования, переименование свойств, шифрование строк, `eval`, защита от отладчика и преобразование потока управления. Декодеров во время игры нет; формулы и порядок расчётов не меняются. Source map не создаётся.

`npm run verify` сравнивает исходный и фактически собранный скрипты при одинаковой последовательности случайных чисел и событий: 3 режима × наличие/отсутствие старой настройки портретного поля × сенсорный/настольный ввод. Сравниваются все команды Canvas и их аргументы, интерфейс и сохранения, включая насосы, свайп, наклон с клавиатуры, встряску, паузу, перезапуск, изменение ориентации устройства при неизменном альбомном поле и обучение. Это проверка эквивалентности в Node.js, а не замена испытаний звука, датчиков и скорости на настоящем телефоне.

Обфускация затрудняет разбор кода, но не предотвращает извлечение, копирование или независимое повторение механики. Если репозиторий с исходниками публичный, эта мера не скрывает опубликованные там исходники; доступ к репозиторию управляется отдельно. Для будущего Android-приложения следует использовать именно релизную сборку из `dist`.

## Управление

- Звук: тихая синтезированная мелодия (80 BPM), короткие пузырьки при нажатии и отпускании, побулькивание струй и отдельные сигналы старта, попадания, неверного цвета, новой волны и результата. Музыка и эффекты отключаются независимо в меню и на паузе; выбор запоминается. Аудио запускается только после действия игрока, на паузе замолкает, в скрытой вкладке AudioContext приостанавливается.
- Все звуки генерируются Web Audio без загрузки файлов. Одновременно не больше 24 голосов; завершившиеся узлы отключаются. У аудио отдельный генератор случайных чисел, не влияющий на физику. `node tools/verify-audio.mjs` проверяет планирование, отключение и очистку звуков.

- Касание слева или справа — левый или правый насос. На телефоне кадр всегда альбомный, насосы доступны по всей высоте.
- В верхних углах — колбы насосов: сколько воды осталось; рядом счётчик нажатий (он же попадает в итоги партии).
- В первой партии поверх игры подсказка: две блеклые полоски — зоны насосов, «слабо» внизу и «сильно» вверху, — палец нажимает на разной высоте, и круг от нажатия тем больше, чем выше. Гаснет сама после пары нажатий каждым насосом; повторить — «Как играть» в меню.
- Чем выше касание, тем сильнее струя; резкий свайп вверх — сильный толчок.
- Насос выдыхается: отпусти, чтобы он снова набрал воду (при этом он подтягивает кольца к соплу).
- Наклон телефона поворачивает «низ» для колец: повернул — кольца съезжают вбок, перевернул — падают к крышке и соскальзывают со штырей, положил плашмя — ложатся на заднее стекло. Отсчёт от того, как телефон держали при старте партии.
- Встряска или удар по телефону толкает кольца и взбалтывает воду. Отключается кнопкой в меню.
- На компьютере: `A` / `L` или стрелки, с `Shift` — сильнее; `Q` / `E` — наклон; пробел — встряска; `Esc` / `P` — пауза.

Датчики движения в браузере работают только по HTTPS (например, GitHub Pages); на iOS игра попросит разрешение при старте партии.

## Физика

- Аквариум узкий: глубина чуть больше диаметра кольца, штыри стоят посередине глубины. Лежащее плашмя кольцо занимает глубину почти целиком — мимо него и мимо штыря другие кольца не проходят; повёрнутое к зрителю кольцо проскальзывает перед штырём или за ним.
- Поле только альбомное. Переключатель ориентации удалён, старое сохранение портретного поля игнорируется. На Android запрашивается landscape-primary; если блокировка недоступна, альбомный кадр сохраняется CSS-преобразованием.
- Кольцо надевается, если верхушка штыря прошла в его дырку (проверяется в объёме): пришедшее сверху плашмя — сразу, стоящее стоймя или наискось — повисает на верхушке и переваливается. Надетое висит с наклоном и тем сильнее трётся о стержень, а легши на полку или на соседнее — выравнивается в ровную стопку.
- Полка-стопор заслоняет струю: лежащее на ней кольцо в тени, чтобы скинуть его, нужно несколько нажатий.
- Насос набирает воду быстрее, чем выдаёт, и при наборе подтягивает кольца к соплу.
- Штыри поток почти не держат, но за ними срываются завихрения.

## Режимы

- **Классика** — надеть все 8 колец на скорость.
- **Два цвета** — красные на левый штырь, синие на правый, за 90 секунд.
- **Волны** — каждая волна приносит больше колец меньшего размера и +12 секунд.

## Инструменты балансировки

Скрипты в `tools/` запускают игру в Node.js без браузера и играют ботом. Константы из `index.html` можно переопределить последним аргументом.

```bash
node tools/sim.mjs 20 600 ALIGN=20,G=200    # партии «Классики»: время прохождения и статистика
node tools/tune.mjs 5 420                   # то же параллельно на всех ядрах, со сводкой
node tools/knock.mjs 20                     # сбивают ли надетые кольца одиночные нажатия и спам
```
